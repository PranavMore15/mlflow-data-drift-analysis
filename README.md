# MLflow Experiment Tracking & Data Drift Analysis

This project demonstrates MLOps concepts including experiment tracking using **MLflow** and data drift detection using **Evidently AI**.

## Project Structure
- `run_experiment.py`: Main script for model training, MLflow logging, and data drift detection.
- `reports/data_drift_report.html`: Generated visual report highlighting data drift results.
- `requirements.txt`: Python package dependencies.

## Prerequisites
- Python 3.10 or higher installed on your machine.
